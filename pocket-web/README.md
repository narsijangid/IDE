# OLKIL Pocket web

Mobile site for the OLKIL VS Code extension. The phone sends a task. The computer runs it.

WebView URL: https://olkil.com/pocket/

```bash
npm install
npm run dev
npm run build
```

Same Firebase project as OLKIL (`olkil-2c8ac`). Deploy `firestore.rules` and `storage.rules` if the site says permission denied.

On the PC: command **OLKIL: Toggle Pocket**, then enter the code on the phone.
