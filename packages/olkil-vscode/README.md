# OLKIL for Visual Studio Code

**OLKIL** is an AI-powered code editor for Visual Studio Code. Write, understand, debug, refactor, and improve code faster with OLKIL AI.

Same [olkil.com](https://olkil.com) account and Lite / Pro / Ultra credits as the OLKIL desktop IDE. Sign in once, then work in the right-hand sidebar (`Ctrl+L` / `Cmd+L`).

## Why OLKIL

- **Codex alternative in VS Code** — agent chat, tool use, and multi-file edits without leaving the editor
- **Powerful IDE workflow** — open files, selection context, Accept / Revert on changes
- **One wallet** — usage matches the OLKIL desktop app (plan credit, not a separate API key)
- **Local engine** — the coding runtime stays on your machine; sign-in is olkil.com

## Features

- Right sidebar agent (Codex-style) with live thinking and tool status
- File-change cards with `+added` / `−removed`, Accept and Revert
- Model picker: Auto, Grok, Claude, GPT, DeepSeek, and more via your OLKIL plan
- Workspace + selection context (`OLKIL: Ask about Selection`)
- Shortcuts: `Ctrl+L` / `Cmd+L` chat, `Ctrl+Shift+L` / `Cmd+Shift+L` new chat

## Install

1. VS Code 1.96 or later
2. Extensions → search **OLKIL** → Install
3. Open the **Secondary Side Bar** (right) and click the OLKIL icon
4. Sign in at olkil.com (Lite, Pro, or Ultra)

Need a plan? [olkil.com/pricing](https://olkil.com/pricing/)

## Desktop IDE

Want the full OLKIL IDE (not only the VS Code extension)? Download it from [olkil.com](https://olkil.com).

## Privacy

Sign-in tokens stay in `~/.olkil/auth-session.json` on your machine. The agent only works in the workspace folder you have open. Provider API keys are never shipped inside this extension.
